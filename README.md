# ListPak

**Live site: [https://www.listpak.com](https://www.listpak.com/)**

ListPak is a free business directory and jobs platform for Pakistan. People use it to find local businesses, companies, professionals and current job openings by city and category — and businesses use it to get discovered online.

## What the platform offers

- **Business directory** — searchable listings across Pakistani cities (Karachi, Lahore, Islamabad, Rawalpindi, Faisalabad, Multan, Peshawar and more) in categories such as restaurants, technology, healthcare, education, retail, construction and finance.
- **Jobs board** — current vacancies by city and field, with company profiles so candidates can research an employer before applying.
- **Professional profiles** — public profiles for freelancers and professionals, with an optional verification badge.
- **Prayer times** — daily prayer timings for cities across Pakistan.
- **Blog** — practical guides for business owners and job seekers, including local SEO and free business listing guides.

## Tech stack

- Next.js (App Router) + TypeScript
- Firebase / Firestore for listings, jobs and profiles
- Tailwind CSS
- Deployed on Vercel

## Repository

This repository contains the production codebase for [listpak.com](https://www.listpak.com/). The sitemap, SEO metadata and directory data are generated from the live database.
